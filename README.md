# 📝 MERN Stack ToDo App

A full-stack ToDo application built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js) that supports **user authentication**. Users can sign up, log in, and manage their personal to-do list securely.

---

## 🚀 Features

- ✅ Add new tasks
- 🗂 View all tasks
- 🖊 Edit existing tasks
- 🗑 Delete tasks
- 🔐 User Signup, Login, Logout
- 🔒 Private task management (user-specific)
- 🌐 Persistent sessions using JWT + cookies

---

## 🛠 Tech Stack

- **Frontend:** React.js, Axios, React Router, Tailwind CSS (optional)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JSON Web Tokens (JWT), Cookies
- **Other:** dotenv, bcrypt, cors, nodemon
